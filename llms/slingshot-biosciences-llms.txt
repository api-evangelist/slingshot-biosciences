## How to read this site as markdown

- Send `Accept: text/markdown` to any canonical URL.
- The same URL serves HTML to browsers and markdown to agents that ask for it.
- Markdown responses omit styling, tracking pixels, and JavaScript.
- `X-Robots-Tag: noindex` is set on markdown responses to prevent duplicate indexing.
